## 🚀 Proyectos Destacados

- **AMORA Forensic Core:** Aplicación de monitorización de red local y respuesta ante anomalías en tiempo real, diseñada con arquitectura offline-first.
- **Payload Image Hunter:** Herramienta desarrollada en Python para el análisis forense de imágenes, desglosado de cabeceras, extracción de metadatos y detección de artefactos incrustados.
- **VR Device & Battery Reporter:** Sistema multihilo basado en scripts de PowerShell y Python conectados vía ADB para la supervisión y monitorización continua del estado operativo de visores VR.
